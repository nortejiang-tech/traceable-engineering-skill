# STAGE-001：为一个本地服务加入版本端点

## 状态

`PLANNED`

## 目标

在既有本地 HTTP 服务中添加只读 `GET /version`，返回构建时版本号。

## 非目标

- 不改变认证、部署方式、数据库或现有端点语义。
- 不发布、不提交、不修改运行环境。

## 设计约束

- 缺少构建版本时返回受控的 `unknown`，而不是抛出未处理异常。
- 现有健康检查与调用方保持不变。

## 验收标准

| 标准 | 验证 | 期望证据 |
|---|---|---|
| 新端点返回 JSON | 聚焦测试 | 状态 200 与精确版本字段 |
| 缺失版本不崩溃 | 聚焦测试 | `unknown` 与状态 200 |
| 既有端点未回归 | 既有测试集 | 实际测试计数与退出码 |

## 验证边界

本阶段不验证生产部署或外部网络连通性；它们属于后续独立阶段。
